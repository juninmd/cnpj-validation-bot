# cnpj-validation-bot
A high-speed Telegram bot for Brazilian entrepreneurs to verify CNPJ authenticity and retrieve business details instantly. It combines live API lookups with a local fallback dataset to ensure availability during critical contract negotiations. | 🤖 Criado de forma autônoma pelo agente github-assistance. Autonomously created by the github-assistance 

## Usage

### Commands
- `/cnpj <number>`: Validate and search CNPJ details.
- `/history`: List the last 5 CNPJs looked up by the user.

### Testing
Run unit tests with `pytest`:
```bash
pytest
```
